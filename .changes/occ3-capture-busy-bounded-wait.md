- Added bounded server-side busy waits for OCC-3 source captures. Registry active-slot declines re-enroll; proven pre-admission scheduler busy declines retry the same native request. Both share one absolute window; quota still fails fast. The scheduler retry needs a streaming capture; a non-streaming capture is still refused at the first decline. A capture admitted after a scheduler wait logs one `capture admitted after busy wait` line.
- Added `OCC3_CAPTURE_BUSY_WAIT_SECONDS` (default 10 seconds, range 0–10). Zero disables both busy waits and the capture reservation. Source admission bound and client resend headroom are 25 seconds by default; receiver admission behavior is unchanged.
- Added a scheduler capture reservation. A source capture declined only because ordinary requests are in flight is parked before admission. While it is parked the scheduler starts no new ordinary prefill, and it admits the capture when the running requests finish. If they still run when the drain time ends, the capture gets the same busy refusal as before and the busy wait retries it. The reservation is not used when a queue limit (`max_queued_requests`), a request timeout sweep (`SGLANG_REQ_WAITING_TIMEOUT` or `SGLANG_REQ_RUNNING_TIMEOUT`) or receive skipping (`scheduler_recv_interval` above 1) is configured. Such a capture gets the busy refusal at once, and the busy wait sends the same request again.
- Added `OCC3_CAPTURE_DRAIN_SECONDS` (default 2 seconds, range 0 to the busy-wait window): the time one parked capture gives running requests to finish while new ordinary prefills wait. The scheduler ends the hold in its next iteration after that time. Each source dispatch gets the first-event bound plus this drain, and re-enrolls and re-dispatches must start in the busy-wait window less the drain, so the 25-second source admission bound does not change.
- Added `OCC3_CAPTURE_PREEMPT` (default `off`: no request is retracted). `retract` is an operator opt-in: plain ordinary requests that still run when the drain ends are retracted and resume from the same output position after the capture turn. A request that cannot resume that way is never retracted. A session request is never retracted. In both cases the capture is declined as with `off`.
- Added the fixed decline codes `capture_drain_seconds_invalid`, `capture_preempt_invalid` and `capture_profile_mismatch`. An invalid `OCC3_CAPTURE_DRAIN_SECONDS` or `OCC3_CAPTURE_PREEMPT` refuses the native installation. The capture knobs are checked for every installation, also when the caller gives an explicit buffer profile. An explicit profile whose busy-wait window or drain differs from the environment settings is refused with `capture_profile_mismatch`. `/occ3/v1/status` shows the code.
- Fixed busy retries after pinned SGLang request normalization while preserving descriptor identity, mutation checks, cancellation, replay fences, and capture deadlines.
- Fixed `/occ3/v1/status` hiding the decline code for an invalid `OCC3_CAPTURE_BUSY_WAIT_SECONDS` or `OCC3_MAX_TURN_SECONDS`.
