Changed: an OCC-3 native enrollment that ages out with its permit (the server bounds `max_ttl_seconds` to one hour and nothing renewed it) no longer fails every later inference request with `Experimental native handoff unavailable or uncertain; replay is forbidden`. `check_model` now treats expiry as terminal-recoverable: it deactivates the native session (the registered tombstone cleanup clears the host hooks and removes the handoff tool) and lets the request take the ordinary inference path, so long-lived sessions degrade to ordinary turns instead of wedging. An explicitly closed session and a model-identity switch still fail closed loudly, exactly as before.

Changed: the daemon's prompt handler re-activates a dead native enrollment before dispatch (`maybe_reactivate_expired_occ3`), so native handoffs work again past the one-hour server TTL without a session restart. The install seam (`install_experimental_native_occ3`) replaces a dead native session instead of refusing, dropping any stale handoff-tool entry; a live session still refuses re-installation.

Why: live wedge (hive agent f24cd1341c53, 2026-11-08): every turn for ~61+ minutes ended with `stopReason=error` and `receiver_refused reason=model_check_failed`, including heartbeats, because the expired enrollment made the installed `receiver_resolver`/`source_hooks` fail every inference request while nothing ever invalidated the state or cleared the hooks. `check_model` returned early from `check()` without any recovery path.

Tests: new `expired_enrollment_deactivates_instead_of_failing_turns` (occ3_state) pins the hook-level recovery on both receiver and source sides plus unchanged live/model-switch semantics; new `expired_enrollment_recovers_terminally_and_clears_host_hooks` and `fresh_enrollment_replaces_dead_native_state` (occ3_invalidate_triggers) pin the AgentSession-level tombstone cleanup and the install-over-dead seam with exactly one handoff tool. Test expiry is injected through a `#[cfg(test)]` per-session clock bias; production always reads the real clock.
