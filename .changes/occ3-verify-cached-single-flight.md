- Fixed concurrent cold OCC-3 activations each minting their own connector instance when the ready cache was empty (two sibling sessions activating 58 ms apart split one cache key across two instances, so a sender and a receiver lost each other's native publication records and the receiver's prepare failed closed as Unauthorized): `verify_cached` now serializes cold handshakes per key and converges on the winner's instance.
- Raised the `occ3_handoff` capture-capacity wait from a fixed 30 s to a 90 s default (`OCC3_CAPTURE_CAPACITY_WAIT_SECONDS`, clamped 5..=240): the wait must cover a sibling sender's whole arm-to-publish window, which is dominated by that model's facts turn (measured about 40 s live), so 30 s forced a noisy re-arm cycle on parallel handoffs.
