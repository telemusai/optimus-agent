- Added bundled `dgx-glm53`, `dgx-k3`, and `dgx-deepseek41` model registrations that ship credential-free and become usable after a DGX auth file is imported.
- Added `dgx-auth export [--out <path>] [--providers <ids>] [--no-refresh]`, `dgx-auth import <file> [--force]`, and `dgx-auth status` commands that share DGX access through self-contained `optimus-dgx-auth/1` JSON files bundling the gateway URL, `X-Pomerium-Authorization` session header, provider keys, and model definitions; export refreshes the gateway credentials first by default through the user-configured `OPTIMUS_DGX_AUTH_REFRESH_CMD` command (must exit 0 after updating `models.json`; output never captured) so each file carries a full-lifetime session, warns when the stored credentials are already expired, and `--no-refresh` skips the refresh.
- Added import safety: identical existing credentials are skipped, differing credentials require `--force`, `models.json` is written atomically, and CLI output lists provider IDs and credential presence only, never secret values.
