- Fixed silent OCC-3-less `rlm` spawns when models.json carries several providers with the same model id (for example `glm-5.3` under `dgx-glm53-occ3`, `dgx-glm53`, and `ollama-cloud`): child model resolution now fails loud when the selection lands on an entry without an enabled OCC-3 configuration while an OCC-3-configured twin of the same model id is authenticated. Both silent paths are covered - inheritance (a parent on the ordinary entry spawned toolless children whenever no model argument was passed) and an explicit ordinary selector - and the refusal names the resolved selector plus the exact OCC-3 selector(s) to use, with no fallback or auto-rewrite. Unambiguous ids without an OCC-3 twin keep the previous behavior.
- Changed the generic `Requested ... model is unavailable` refusal for `rlm` spawns: a bare model id shared by multiple providers now lists the exact `provider/id` selectors, OCC-3-configured entries first, so a wrong or ambiguous reference can be disambiguated instead of debugging a missing native tool.
