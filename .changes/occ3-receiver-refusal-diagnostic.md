- Added a content-free `receiver_refused` warning (component `occ3.receiver`) for each fail-closed exit of the OCC-3 receiver resolver. It names the exit (for example `prepare_inference_refused`, `registry_unsupported`, `inbox_claim_refused`), the message id when one is known, and the connector error kind. It never logs envelope content, facts, keys or server text. The turn still returns the same generic refusal, so behavior is unchanged; the log only makes a live "unavailable or uncertain" receiver failure diagnosable.
