- Provider stream partial messages for Anthropic, Google, Google Vertex, and Mistral are now built in a single pass and accumulated in place instead of being deep-copied on every token, cutting per-stream allocation bytes by roughly a third to two-fifths on those providers while keeping every emitted partial value identical.
- The agent loop and daemon wire no longer clone the partial message on every streamed delta: the per-delta out-parameter copy is derived once at abort or error exits, and six redundant clone or re-serialize rounds on the daemon event path (session store, compact-delta construction, JSONL persistence, client reconstruction) are removed.
- Codex WebSocket frames no longer pass through a JSON envelope before parsing, listener dispatch no longer clones events per listener in the single-listener steady state, and the parse stream pops from one shared queue instead of two: about ten fewer allocations per frame at every payload shape, with listener-observed event shapes, abort precedence, and the JavaScript-compatibility seam preserved and pinned by new regression tests.
