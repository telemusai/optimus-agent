- Raised the calibrated candidate profile's `label_anchor_alpha_default` from 0.0 to 0.3 in `deploy/native-build-inputs/native-profile-input.json.v3` and the `occ3-icalib-persistent-candidate` plan template, so a client that omits the request field is anchored at the attested hybrid coefficient instead of silently dropping to 0.0 - the exact garbling class the PR #265 client default (env > file > client-default 0.3) fixed client-side. An explicit 0.0 request still selects zero; this is a binding-digest change, so clients re-activate through the existing authority path. The legacy per-message packaging default (`native-profile-input.json`, 613698c4...) stays the historical fixed zero-profile with its immutable SHA pins.
- Wired `occ3_quarantined_tokens` into the busy-time invariant check: the patched `init_invariant_checker` now constructs a quarantine-aware `SchedulerInvariantChecker` subclass whose `_get_total_uncached_sizes` adds the live quarantine counter to the full-pool uncached budget, mirroring the idle path's `uncached=self.occ3_quarantined_tokens`. Previously a quarantined private row (mark_kv_released while its pages stay allocated) tripped the hard leak assert and crashed the scheduler whenever `SGLANG_ENABLE_STRICT_MEM_CHECK_DURING_BUSY` was enabled; other leaks are still reported.
- Added a bounded TTL sweep to `ControlClient._uncertain`: a lost control reply (dispatch accepted, reply never arrives) leaked its pending-table entry forever, and `max_pending` leaked entries refused every later control op with "quota" until process restart. Entries older than four dispatch timeouts are now released on each call; the sweep is fail-closed on uncertainty - it only frees quota accounting, never claims the operation did not run, ignores late replies like any unknown command id, and leaves cancellation-resistant operation tasks holding their quota slot through `self._operations`.
- Fixed the stale tombstone annotations in `latent_registry.py`: `tombstone_attempts`/`tombstone_handles` entries are documented and asserted as 4-tuples `(expiry, final state, principal digest, session id)`, while `tombstone_publications` keeps the 2-tuple `(expiry, final state)`.
