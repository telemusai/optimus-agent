- Session event-log and session-file writes are now grouped in a timed in-process buffer (session 100 ms, event log 250 ms, chosen from a measured probe with an environment override available) with a size cap, forced flushes at every durability boundary, and a fail-closed sticky-error contract, cutting write syscalls per streamed turn roughly fivefold on sessions and elevenfold on event logs while keeping every written byte identical.
- Model-response JSON parsing now uses borrowed typed single-parse fast paths for OpenAI-compatible, Anthropic, Google, Google Vertex, Mistral, Bedrock, and Kiro streams with the previous generic parsing kept as a fallback, removing per-event allocations (-6% to -45% of stream allocations depending on provider) with parsed event sequences byte-identical.
- Local compaction data-parallel stages (token estimation, extraction, conversation conversion and serialization, restore parsing) now run on scoped threads above measured size crossovers with bit-identical output assembly, and any failure or small session falls back to the unchanged sequential implementation.
- Session-loop hot paths are cheaper: Jev settings are shared behind an Arc instead of deep-cloned per read, message-update extension payloads are only serialized when an extension actually listens for them, and the agent loop moves its owned context instead of cloning the full history per run; turn latency drops about a fifth with a third fewer allocations per turn.
