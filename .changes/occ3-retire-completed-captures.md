- OCC-3 senders now retire a completed capture's server reservation as soon as the receiver's proven-completion delivery event is routed back, instead of holding the reserved live bytes until the sender's next arm or its session teardown. Two finished one-shot senders previously saturated the server's 256 MiB live-byte budget until expiry, wedging every later capture with a terminal 409. The retirement is guarded by the slot's own published message id, admitted flag and Captured lease state, so a sender already re-armed for a later queue entry is untouched; a new `native_session_closed` warn line (content-free: had_lease/retirable booleans) makes teardown leaks visible.
- The SGLang OCC-3 backend now maps a `quota` refusal at `reserve_capture` to the same retryable `scheduler_busy` 503 contract as the registry `busy` decline (both fire before any record, attempt or byte charge, so non-use holds), instead of a terminal 409 that strands the sender while the live-byte budget is saturated.
