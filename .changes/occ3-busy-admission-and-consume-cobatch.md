- Fixed an active OCC-3 turn refusing a new capture reservation with a generic failure: it is now HTTP 503 `scheduler_busy` with `Retry-After: 5`, and the `_charge` adapter concurrency refusal uses the same 503 contract instead of 429.
- Fixed a consume behind an active capture getting a generic 409: `reserve_consume` now declines `busy` before taking the nonce, attempt or lease, and the backend maps it to 503 `scheduler_busy` like the capture decline.
- Fixed unbounded growth of terminal registry records, backend attempt slots and worker control-reply cache entries: they are pruned after bounded grace windows, so a long-lived server keeps admitting after many arm/retire cycles.
- Changed consume turns to no longer need an empty batch: the prefill runs as a one-request eager extend batch beside ordinary decode, then the row leaves the eager cohort after its final injected chunk and decodes in the shared batch with CUDA graphs. Capture turns stay exclusive with the immediate pre-use 503 `occ3_busy_batch`.
- Changed consume result settle to journal only the terminal step, so a shared decode batch never runs a per-step cross-rank gather; the terminal receipt reads only integers, token digests and injection metadata, never decode numerics.
- Fixed a consume whose cohort release is refused at its final prefill chunk (record retired or expired) staying eager beside ordinary rows, which made the next `merge_batch` a fatal `occ3_mixed_cohort` for every user: the row is now aborted through `commit_failed` with its private KV freed, and an extend settle aborts any consume still eager and not the chunked row.
- Fixed an overlap overshoot tick overwriting an already aborted consume's finish reason and length; the settle skips rows latched by `occ3_abort_done`.
- Fixed a consume admitted with no free request slot or KV parking until the 5 s queue bound and ending in a dispatched, non-releasable `admission_timeout`: admission now declines it pre-use as `occ3_busy_batch` (rank-uniform, inside the admit preflight) only when no request slot is free or KV cannot hold its rewritten prompt; queued ordinary requests do not count, because the pending consume is scheduled ahead of the waiting queue.
- Changed attached OCC-3 rows to never be preemption victims and to be retracted last; ordinary rows beside them stay preemptible and retractable.
- Fixed a resend after a retryable busy 503 returning 409 `replay_forbidden`: the adapter replay fence is now released only when the attempt provably never ran (a registry `busy` decline, a scheduler `occ3_busy_batch`/`occ3_busy` decline, or an `admission_timeout` before dispatch, with no native output and no stream hand-off). Every other ending, including `admission_timeout` after dispatch, keeps the fence.
- Added the all-rank control operation `release_lease`: before a busy-declined consume is unfenced, the worker proves the lease was never admitted, returns the nonce and lease to `published`, and tombstones the declined attempt id. A busy-declined capture is unfenced only after its never-admitted record is retired.
- Changed the native image: `patches/scheduler-cache-ipc.v1.json` and the adapter, backend, registry and worker sources changed, so a MODE=full rebuild is required and the frontend and worker must ship together. `RuntimeProfile` is unchanged.
- Changed `capture_prenorm` and `stage_verify` to drop a redundant `clone()` after `index_select`.
